# 开发回归检查

在本地9001工作区执行：

```powershell
pwsh -NoProfile -File D:/xianyu-auto-reply/scripts/test-regression.ps1 -Services -Browser
```

默认检查全部Node用例及前端TypeScript/生产构建；`-Services`追加后台、WebSocket、调度服务的Python测试；`-Browser`追加七个浏览器流程。任一步失败会返回非零退出码。

## 本地约定

- 已安装前端依赖和npx，三个`xianyu-codex-local-*`服务容器已运行。
- 9001必须服务当前工作区的`frontend/dist`。入口会先比较编译和访问到的index.html，防止误测旧构建。
- Python测试按服务隔离各自的`app`包。数据库用例使用连接私有临时表或限定测试身份，平台调用采用模拟。
- 每个服务的测试目录使用本次独立UUID，结束后清理，避免历史用例被再次发现。
- 上游广告迁移和结算用例使用随机`xy_upstream_test_`独立数据库。入口通过本地MySQL容器既有环境临时授予该前缀权限，结束撤销，测试自行清理新建数据库；不改业务库权限。
- 浏览器测试拦截全部API，使用合成账号和素材；真实商品发布、退款、订单上传和面单取号不会被调用。
- 截图位于`output/playwright`。测试用独立浏览器会话，不读取用户现有登录会话。

## 覆盖范围

- 发布列表：旧响应与旧错误不回写、加载状态、10/20/50/100条、首页尾页及跳页、筛选重置、总数减少归位、素材库当前页选择、手机分页。
- 批量素材选择：100条勾选、切页和切换来源后保留选择、仅看已选、越界跳转和手机布局。
- 清空历史：确认前不写入、已结束记录清空、未完成及待核查保留、跨标签任务列表和进度同步、刷新后结果保持。
- 发布辅助页面：地址、素材选择、AI列表、续售和批量任务公共分页，普通用户只读权限，素材详情预览竞态，任务读取失败恢复，双日志标签清空各刷新一次。
- 任务勾选删除：确认前不写入、当前页选择、六类未完成或待核查状态保护、错误保留选择、处理中防重复、精确范围、跨标签刷新及发布日志保留。后台另覆盖真实ORM认证用户在事务回滚后的业务失败响应。
- 上游同步：公开首页/登录导航、广告位置隔离、个人Token测试与保存重读、系统设置六标签、手机操作；后台验证凭据脱敏、配置归属与回退、旧广告结构双次迁移、历史付款关联保护及关联订单重复/并发结算。
- 发布店铺展示：紧凑目标多选下拉、当前店铺默认与清空保持、搜索/键盘/点击外部关闭、错误重试与空态、手机边界；目标和素材来源独立，预检原ID与数量不变；发布日志昵称、同名ID及会员名/删除账号回退。
- Node用例覆盖发布参数及原有素材类目、SKU、店铺隔离、退款验证和打单接口参数。
- 服务用例覆盖现有发布队列、素材导入/重新导入、资料补全、退款验证、打单授权等。
