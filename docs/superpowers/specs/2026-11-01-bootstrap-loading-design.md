# 初始化加载优化设计

用户授权在不删除、不削减、不损坏现有功能的前提下优化整站加载。

只调整前端初始化读取。继续等待服务器验证登录成功，之后并行读取免责声明同意状态和系统设置；两项检查完成之前不展示受保护页面。每项读取沿用原有成功、失败和权限处理。

通过保护路由内的React Context传递本次系统设置结果，供页面外框首次挂载时读取系统名称，避免重复请求。结果只存在本次组件生命周期内，不增加跨用户或持久化缓存；初始化失败时外框保留原有重新读取路径，后续名称更新仍走已有事件。

选择此方案是因为改动集中于两个入口。跨页面通用缓存需要额外处理设置更新失效、账号隔离和权限变化；线路或CDN调整涉及部署环境，本轮不引入。

验收覆盖并行请求先后、两种响应顺序、登录无效、声明未同意与请求失败、菜单权限、主题/名称、名称实时更新及初始化失败后的重试。既有发布、订单、素材和卡券业务继续执行完整回归，不触发真实业务写操作。
