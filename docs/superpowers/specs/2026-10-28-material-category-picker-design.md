# 素材库批量修改类目优化

用户要求优先处理：已导入素材可以自行批量修改已有平台类目，参考原9000功能，尤其能选用已保存的“其他闲置”。

复用现有replace预览、快照令牌、确认保存和权限隔离，不另造保存接口。

- 按用户确认，只保留勾选素材后原有的“批量设置类目”入口；其中“统一修改所选”使用优化后的类目选择，保留“仅补全缺失”。删除顶部重复的“批量修改类目”按钮。
- 目标类目支持按关键词获取平台候选，关键词不修改商品原文；也可选择本页已有素材的完整类目，不硬编码平台ID。
- 逐件显示原类目与目标类目；明确确认后保存，仅更新所选素材。切换店铺关闭类目弹窗，避免旧店铺状态串用。
- 原有并发快照保护、100条上限、类别身份变化清空旧属性、保留无关字段继续有效。
- 失败日志保留真实平台返回；不把改类目等同于保证发布成功；本轮不真实发布或修改用户素材。

验证：类目来源去重、关键词独立、真实MySQL保存与冲突/权限回归、页面入口和弹窗交互、构建。
