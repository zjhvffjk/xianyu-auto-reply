# 发布店铺选择与日志昵称显示

用户要求批量发布目标店铺像卡券页一样使用紧凑下拉，并让发布记录账号列显示闲鱼昵称。

## 设计

将目标店铺选择移动到批量发布标题旁，下拉内提供搜索和原有多选；收起时显示单个昵称或已选数量。沿用现有已验证账号名称函数、店铺状态、当前店铺默认选择、原始ID提交和预检查失效逻辑。目标选择不改变素材来源或全局当前店铺。下拉支持键盘关闭、点击外部关闭和手机边界收敛，保留加载、错误重试与空账号提示。

日志账号列调用getAccountNickname，保留ID次级信息供同名识别；缺少昵称依次沿用未打码的会员名及账号ID。私有备注不充当昵称，筛选、核查、分页与后台权限保持。只涉及前端，无新增后端或数据库迁移。
