# 初始化加载优化实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 减少登录后初始化的串行等待和重复读取，保留全部现有功能。

**Architecture:** 登录验证后并行执行两个独立读取；保护路由通过Context传递本次设置，外框首次挂载复用，失败继续重试。所有业务API、权限条件及设置更新事件保持现有行为。

**Tech Stack:** React、TypeScript、Vite、Playwright。

**Spec:** docs/superpowers/specs/2026-11-01-bootstrap-loading-design.md

## 约束与检查重点

不删除功能、不变更业务数据和接口、不引入持久化或跨账号缓存。重点检查鉴权之前不请求私有配置、未完成检查不放行、免责声明不跳过、失败后仍能恢复、名称更新事件不被旧值覆盖。

## 验证记录

基线通过延迟门闩复现：免责声明未返回时，系统设置尚未发起。实现后专项验证7种场景通过，正常设置请求2次降为1次；两个并行401共用一次刷新并恢复请求。失败重试依旧为2次请求，声明失败仍要求确认。

53项Node、260项服务测试、前端构建及原有7组浏览器回归通过。新增主题断言首次因测试数据使用不存在的orange预设而失败，已对齐为现有合法amber预设，专项重新通过；产品主题逻辑未修改。最后再次统一执行Node、构建及全部8组浏览器流程，退出码0。独立只读审查未发现阻断项。上线核查结果保存到项目任务记忆。
