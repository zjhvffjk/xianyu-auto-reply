# 9001维护版说明

本仓库 Fork 自 `zhinianboke/xianyu-auto-reply`，以原作者 `a58dea0d8ef43d4f467f09b5607af4821710700a` 为合入基线，保留原作者提交历史，叠加9001维护功能，不继承WorkBuddy旧版开发历史。

## 功能范围

- 按店铺管理商品、卡券关联与发货配置。
- 复用商品管理的素材导入、历史商品状态及类目批量补全。
- 按完整文案进行标题与正文AI润色，预览确认后采用；标题30字、正文1500字。
- 素材选择、批量发布、北京时间定时发布、任务状态与发布记录。
- 退款消息及已有仅退款申请的手动批量核对与官方核验。
- 公开服务状态、真实在线数量、后台账号启动进度及故障提示。

临时自动退款已撤销，不包含支付密码保存或代输功能。
